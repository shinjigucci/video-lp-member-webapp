# 10分動画LP台本メーカー 完全版

講座受講生向けにURL共有できる、会員限定Webアプリです。

## できること

- 商品情報またはLP画像の入力
- 冒頭30秒フック100案生成
- 自作フックからの10分動画LP台本生成
- 3,700〜4,200文字を目安にしたフル台本生成
- AIアバター用原稿生成
- 読み注意メモ生成
- 50〜60枚のスライド構成生成
- 1枚ずつGPTに貼れるスライド画像生成プロンプト出力

## 会員限定化

`MEMBER_ACCESS_CODE` を設定すると、アクセスコード入力後だけアプリを使えます。

未設定の場合は、従来どおりログインなしで使えます。

## APIキー運用

### 講座特典として使う推奨設定

サーバー側に `OPENAI_API_KEY` を設定します。
この場合、受講生の画面にはAPIキー入力欄を出しません。

### 受講生自身のAPIキーで使わせる設定

`OPENAI_API_KEY` を設定しなければ、画面上部にAPIキー入力欄が表示されます。

## ローカル起動

```powershell
$env:MEMBER_ACCESS_CODE="受講生用コード"
$env:OPENAI_API_KEY="sk-..."
npm start
```

URL:

```text
http://localhost:8788
```

## 環境変数

| 変数名 | 必須 | 内容 |
| --- | --- | --- |
| `OPENAI_API_KEY` | 推奨 | サーバー側で使うOpenAI APIキー |
| `MEMBER_ACCESS_CODE` | 推奨 | 会員ログイン用アクセスコード |
| `OPENAI_MODEL` | 任意 | 既定値は `gpt-4.1` |
| `PORT` | 任意 | 既定値は `8788` |

## 公開先

Node.jsが動くサーバーで公開できます。

- Render
- Railway
- Fly.io
- VPS
- さくらVPS
- Xserver VPS

WordPressの固定ページだけではNode.jsアプリは動きません。
WordPressで見せる場合は、別サーバーにこのアプリを置き、会員ページからリンクする形が安全です。
