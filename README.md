# インパクト型10分動画LP台本メーカー

広告で手を止める冒頭フック100案、10分動画LP台本、100点満点の採点、改善版まで作るWebアプリです。

## ローカル起動

```powershell
npm start
```

URL:

```text
http://localhost:8790/
```

## OpenAI APIキー

どちらかで設定できます。

- 画面上部のOpenAI APIキー欄に一時入力する
- Renderなどの環境変数 `OPENAI_API_KEY` に設定する

Render公開時は、環境変数で設定するのがおすすめです。

## Render公開

`render.yaml` を使ってRenderにデプロイできます。

環境変数:

- `OPENAI_API_KEY`: 必須
- `OPENAI_MODEL`: 任意。初期値は `gpt-4.1`

## 主な機能

- 商品情報の入力
- 冒頭30秒フック100パターン生成
- ユーザーによる自作フック入力
- 選択フックを使った10分動画LP台本生成
- 100点満点の採点
- 90点未満の場合の改善案
- 改善指示に基づく再生成
